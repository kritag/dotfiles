# Dotbot plugins

Plain copies of the plugins the configs load, so the repo has no plugin submodules.
Each file keeps its upstream license (`LICENSE.<name>`).

- `sudo.py`: https://github.com/kritag/dotbot-sudo (fork of DrDynamic/dotbot-sudo)
- `yum.py`: https://gitlab.com/flyingchipmunk/dotbot-yum
- `yay.py`: https://github.com/kritag/dotbot-yay. Rewritten: one `pacman -Qq` check, one batched install, `pacman:` and `yay:` directives.
